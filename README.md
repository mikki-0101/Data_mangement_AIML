# Porsche Taycan — Landing Page

A desktop-focused Porsche Taycan landing page created as a personal HTML & CSS practice project. The design focuses on recreating a clean automotive-style interface with strong imagery, spacing, typography, and visual sections.

> **Status:** Completed — Personal Practice Project

## Preview

## Features

- Porsche Taycan-inspired landing page design
- Desktop-focused layout
- Large hero section with vehicle imagery
- Structured navigation and content sections
- Visual cards/image-based sections
- Clean spacing, alignment, and typography
- Styled UI elements and call-to-action buttons
- Static frontend design with no JavaScript functionality

## Getting Started

### 1. Clone the repository

```bash
git clone <your-repository-url>
cd Porsche
```

### 2. Open the project in VS Code

Open the project folder in Visual Studio Code.

### 3. Run with Live Server

Install the **Live Server** extension in VS Code, then:

1. Open `Porsche.html`
2. Right-click inside the file
3. Select **Open with Live Server**
4. The webpage will open in your default browser
